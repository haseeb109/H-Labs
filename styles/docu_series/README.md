# Docu-Series Episodes

Each hearing of the same defendant is the next episode: 'previously on' from the earlier episodes, the updated case file, EPISODE n card, the hearing, a cliffhanger.

No channel name, intro or watermark: add your branding in the editor.
Renderer: ucf/render_doc.py (doc_style = docu_series). Brain fields: prompts/extra.md.
